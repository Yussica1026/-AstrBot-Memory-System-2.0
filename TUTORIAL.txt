AstrBot 记忆系统 2.0 使用说明

安装：
1. 将本仓库放入 AstrBot 的插件目录。
2. 重启 AstrBot 或在插件管理页重新加载插件。
3. 插件会自动创建 memory_manager.db。

常用 QQ 指令：
/memory save <分类> <内容>      保存记忆
/memory query <分类> [数量]     按分类查询
/memory search <关键词>         关键词搜索
/memory today                   查看今日记忆
/memory count                   统计记忆数量
/memory surface                 主动浮现记忆
/memory reindex                 重新计算关联

可用分类：
happy / daily / sad / important / fight / milestone

示例：
/memory save important 今天完成了记忆系统 2.0 的 README 和插件仓库。
/memory query important 5
/memory search 记忆系统
/memory surface

说明：
- Core 记忆不会衰减，需要通过 LLM 工具 memory_mark_core 标记。
- Event 记忆会按时间、重要度、激活次数和情绪强度衰减。
- Archive 记忆默认不主动浮现，但关键词搜索仍可找到。
